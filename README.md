# RastreIA



O que foi Criado:
Criamos uma solução desktop chamada RastreIA, que recebe documentos de casos fictícios, extrai informações relevantes, organiza os acontecimentos em uma linha do tempo e apresenta possíveis conexões para a revisão do caso por uma pessoa.

Quem vai utilizar:
Será utilizado por investigadores criminais e profissionais de análise investigativa.

Como será Usado:
O investigador ou a autoridade irá inserir as informações dos boletins e dos crimes e, com isso, a ferramenta irá analisar os dados e criará sugestões.
